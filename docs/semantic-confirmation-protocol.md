## 指标定义

检索单位为前五个片段。设某有依据题的参考文件集合为 E，前五片段涉及的文件去重集合为 R。多个片段来自同一个文件时，在 R 中只记一次；但它们仍会占前五片段的名额。所有检索指标仅在 28 道有依据题上统计，不把无依据题的空 E 当作自动满分。

| 指标 | 单题定义 | 汇总含义 |
| --- | --- | --- |
| Hit@5 | E 与 R 的交集非空记 1，否则 0 | 至少命中一份预期文件的题目比例 |
| 标准来源 Recall@5 | 交集文件数 / E 文件数 | 先按题计算再取宏平均，表示参考文件召回份额 |
| 完整来源@5 | E 全部包含在 R 中记 1，否则 0 | 全部参考文件齐全的题目比例 |
| MRR | 首个预期文件在前五片段中排名的倒数，未命中为 0 | 首个相关来源排序；不能代替全部来源完整性 |

**Hit@5 与标准 Recall@5 不是同一指标。**例如一题需要两份文件，仅取回其中一份，则 Hit@5 为 1、标准 Recall@5 为 1/2、完整来源@5 为 0。单来源题时前两者相同。若现有报告字段叫 `recall_at_5`，其实现却只统计交集是否非空，应在展示时注明那是 Hit@5，不能据字段名把它解释为标准召回率。

以上按文件计算，命中同文件的错误段落仍可能得分。不能把它们说成段落标注意义上的标准召回率，更不能把它们当作答案事实正确率。多源题需逐条核对全部参考事实，并单列 4 道多源题的完整率，避免总平均掩盖遗漏。

拒答率以 8 道无依据题为分母：状态为 `insufficient` 的比例；其余状态计为误接受。有依据误拒答率以 28 道有依据题为分母。语义相关不等于回答属性充分，因此不能只报告 Hit@5 而隐藏误接受。

引用有效性只检查编号与原文对应，提示词覆盖只检查参考词项出现，均非语义正确率。若报告人工回答正确性，必须另外写明逐结论的判分方法、核验人员与分母；不能用自动词项结果替代。

延迟区分冷启动加载/索引构建与预热查询，说明是否包含 HTTP、浏览器和生成调用；小题集 CPU 测量不能外推企业并发性能。样本量小、领域单一，不做显著性或稳定泛化结论；比较结果按实际测得陈述，不预填提升。
