## 失败演示的复盘方法

打开 `holdout-036` 的参考答案与实际来源：问题问年费和折扣，`trial.md` 只有会员配额等事实。依次判断：原文没有价格 → 解析不是主要问题 → 检索拿到同主题 → 状态判为 answered → 应记录误接受。不要把它叫“模型幻觉”，本次没有模型调用。

再看 `holdout-007`：资料有断网本地记录和补传规则，但改述问法没进候选。先看中文字符词项与共享门限，再看排序；换大模型无法可靠补回没检索到的规则。当前可做失败分析，不在这个已看过的 holdout 上反复调参后继续宣称独立提升。

## 有额外两分钟时演示删除闭环

1. 上传自己的 `练习.txt`，仅写「演示资产代号为松果七号」。
2. 提问「演示资产代号是什么？」，核对该文件来源。
3. 在知识文档删除这份练习资料，确认列表消失。
4. 新会话重新提问，确认新检索不再引用该文件。历史回答和下载快照属于过去结果，原电脑 TXT 也会保留。

不要删真实资料或为演示清空整个数据库。扫描件、损坏 PDF、非法模型引用等失败适合结合测试说明；不需要伪造服务故障或修改固定题集。启动、浏览器操作与真实模型是不同验收项，分别报告证据。
